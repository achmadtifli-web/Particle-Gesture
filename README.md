# Hand Gesture Particle

Real-time hand gesture particle visualization menggunakan Python, OpenCV, MediaPipe, dan Pygame.

Program mendeteksi beberapa gesture tangan dan mengubahnya menjadi bentuk partikel.

## Features

- Fist -> Heart
- One Finger -> LOVE
- Two Fingers -> Star
- Five Fingers -> Circle
- Pinch -> Spiral
- Idle -> Floating Particles
- Particle gathering animation
- LOVE heartbeat animation
- Real-time webcam hand tracking

## Technologies

- Python
- OpenCV
- MediaPipe
- Pygame

## Requirements

Python 3.14

Dependencies:

- mediapipe==1.0.1
- opencv-python
- pygame
